How to use Nova

A practical guide to chats, files, Projects, Memory, images, and account features available in Nova.

Getting started

Open a chat and ask in your own words. Use New Chat for a separate topic; choose a model from the model selector when you want to change which available model answers. Your conversations appear in the Sessions list and can be reopened later.

Nova names a conversation after a meaningful first message. A greeting can remain “New Chat” until you ask about a topic.

Chat

Nova keeps conversational context in the current conversation, so follow-ups can refer to what you just discussed.

Explain quantum computing simply.Make that easier to understand.Give me an example.

Start a new chat when you want a clean context.

Work with files

Attach a supported file in the composer, then tell Nova what to do with it. Upload and analysis support depends on file type and size.

Summarize the attached report in five points.Compare the totals in these two spreadsheets.Explain the main ideas in this document.

Projects

Use Projects for work that needs an organized goal, tasks, notes, or project files. Create one from the Projects workspace, review its plan, and open it to continue.

Create a project to build a simple website for my business.

For one-off questions or advice, use a normal chat. Projects help keep longer work organized; they do not guarantee that every planned action can run without review.

Project execution

Execution controls apply to the selected project. Next runs the next available step. Continue resumes work where supported. Run All proceeds through runnable work. Pause requests a pause; Approve confirms an action when Nova asks; Stop stops the current run; Reset resets project execution state.

Review proposed work and approval prompts. If Nova reports that a step is blocked, read the blocker and update the project plan or inputs before trying again.

Memory

Nova Memory is for information you choose to save so it can be available as personalization context later. You can review and manage saved items in the Memory panel. Do not save sensitive information unless you intend Nova to retain it.

Generate images

Describe the image you want using the image command. Some requests are blocked by image-safety systems; revise the description and try a different prompt.

/image a cabin beside a mountain lake at sunset

Generate videos

On Nova servers with video generation enabled, enter /video followed by a description. You can also attach an image and ask Nova to animate it. Generation runs in the background; when it finishes, the playable video appears in the conversation and in Artifacts. The current provider uses Ray 3.2, with a 5-second, 720p, 16:9 default. Some requests may be blocked by the provider's safety system; change the description and try again. If Nova says video generation is not configured, this server has it disabled or is missing its provider configuration.

/video waves beside a glass house at sunsetAttach an image, then ask: “Animate this with a slow camera move.”

Voice and Speak

Voice listens to speech using browser speech recognition when the browser and device provide it. Speak reads the latest assistant reply aloud using browser text-to-speech. Available voices and recognition support come from your device/browser.

Projects or normal chat?

Ask a normal question

How would I build a website?

Use chat to get an explanation, advice, or a short answer.

Start organized work

Create a project to build my website.

Use Projects when you want Nova to organize a longer goal into tasks and project material.

Account and security

Sign in with your Nova account. New accounts may require email verification. Use Forgot password on the sign-in page to request a reset. Multi-factor authentication can be configured from your account security settings when available for your account.

Troubleshooting

Nova can't connect or a model is unavailable

Check your connection and retry. If it continues, choose another available model and try again later.

A file upload failed

Check the file type and size, then retry. You can also paste a short excerpt into chat.

Project execution is blocked

Open the project and read the blocked step's explanation. Add the missing information or resolve its dependency before continuing.

Image generation was blocked

Rephrase the prompt with a different subject or details. Nova does not bypass image-safety restrictions.

You can't sign in

Check your username or email and password. Use password reset, and complete email verification if requested.
