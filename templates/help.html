Welcome to Nova

Learn how to use your AI workspace.

Nova helps you plan, create, organize, and continue your work without starting over. This guide explains every major feature and how to get the best results.

01 • First Steps

Start by explaining your goal.

Nova works best when you explain:

• What you are building
• What problem you have
• What result you want

Example:
"I want to build an app. Help me plan the first version."

02 • Chat

Ask Nova questions and solve problems.

Use Chat for:

• Learning
• Writing
• Debugging
• Brainstorming
• Making decisions

Example:
"Explain this error and help me fix it."

03 • Memory

Let Nova remember important information.

Memory helps Nova remember useful things.

Good examples:
"Remember my project uses Python."
"Remember I prefer short answers."
"Remember our goal is launching this app."

Do not save passwords, API keys, or private information.

04 • Sessions

Keep different work organized.

A session is like a separate workspace.

Use different sessions for:
• Different projects
• Research
• Learning
• Planning

Return later and continue where you stopped.

05 • Files and Uploads

Give Nova information to analyze.

Upload:

• Screenshots
• Documents
• PDFs
• Code files
• Images

Example:
"Review this file and explain the important parts."

06 • Project Brain

Keep your project direction clear.

Project Brain helps Nova understand:

• Your goal
• Important decisions
• Current problems
• Next steps

Example:
"What should I work on next?"

07 • Planning

Turn ideas into steps.

Use planning when you need structure.

Examples:
"Create a launch plan."
"Break this project into steps."
"Help me choose the best approach."

08 • Execution

Move from plans to action.

Execution helps you work through tasks.

Examples:
"Start the first step."
"Help me complete this task."
"Check my progress."

Getting better answers from Nova

The best results come from giving Nova context.

Instead of:
"Fix this."

Try:
"Fix this login problem. My app uses Flask sessions and the problem started after an authentication update."

More information helps Nova understand what you need.
