# Establish the Website Structure and Shared Navigation

## Core Site Pages

1. **Homepage**
   - Serves as the main landing page.
   - Provides an overview of the website purpose and key features.
   - Includes navigation links to other core pages.

2. **Contact Page**
   - Allows users to reach out via a contact form or provided contact details.
   - May include address, phone, email, and a simple contact form.

3. **Testing Phase Page**
   - Enables users to participate in or view the ongoing testing phase.
   - Could include forms, instructions, or feedback mechanisms related to testing.

## Navigation Structure

- The website will have a shared navigation menu accessible from every core page, typically positioned at the top of the viewport.
- Navigation menu items:
  - Home
  - Contact
  - Testing Phase

## User Flow Between Pages

- Users start at the Homepage by default.
- From the Homepage, users can click on:
  - "Contact" to go to the Contact Page.
  - "Testing Phase" to access the Testing Phase Page.
- From the Contact Page or Testing Phase Page, users can:
  - Use the shared navigation menu to return to the Homepage or switch between Contact and Testing Phase pages.
- The navigation menu remains consistent across all pages, ensuring seamless movement throughout the site.

This structure supports straightforward exploration and ensures users can quickly access essential information with minimal clicks.
